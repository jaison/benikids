Todas sob a **SIL Open Font License 1.1** (https://openfontlicense.org), baixadas do repositório
oficial do Google Fonts (https://github.com/google/fonts):

| Arquivo | Fonte | Autores |
|---|---|---|
| Bangers-Regular.ttf | Bangers | The Bangers Project Authors |
| Bungee-Regular.ttf | Bungee | David Jonathan Ross |
| Shojumaru-Regular.ttf | Shojumaru | Brian J. Bonislawsky (Astigmatic) |
| Fredoka.ttf | Fredoka | The Fredoka Project Authors |
| Fredoka-SemiBold.ttf | Fredoka (instância estática, peso 600) | The Fredoka Project Authors |

`Fredoka-SemiBold.ttf` é uma instância estática da `Fredoka.ttf` (eixos `wght=600`, `wdth=100`),
gerada com o fontTools (`fontTools.varLib.instancer`), para o menu nativo (`cliente/`), que não
aplica o eixo de peso de fontes variáveis.
